# GymFlow 🏋️‍♂️

**GymFlow** es una solución integral diseñada para la gestión y administración eficiente de gimnasios. Este proyecto monorepo integra una API backend robusta, una aplicación móvil y un cliente web para centralizar el control de usuarios, membresías y servicios.

## 🚀 Arquitectura del Proyecto

El repositorio está estructurado en los siguientes módulos:

* **`backend/GymManagement.api`**: API RESTful desarrollada en C# / .NET para manejar la lógica de negocio, autenticación y persistencia de datos.
* **`mobile/`**: Aplicación móvil multiplataforma desarrollada con Dart / Flutter para usuarios y entrenadores.
* **`web/`**: Panel de administración web construido con TypeScript para la gestión centralizada de la plataforma.
* **`docs/`**: Documentación técnica, definiciones de roles y guías de arquitectura.

## 🛠️ Tecnologías Utilizadas

* **Backend:** C#, .NET, C++ / CMake
* **Mobile:** Dart, Flutter
* **Web:** TypeScript, HTML5
* **Base de Datos:** SQL / Relacional
